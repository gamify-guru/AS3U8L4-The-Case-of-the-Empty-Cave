# The Case of the Empty Cave — Interactive Grammar Boss Battle

Интерактивный урок английского языка по грамматике **There was / There were**.

**Тема:** Academy Stars 3, Unit 8, Lesson 4  
**Формат:** Boss Battle / детективная история «Пустая пещера»

## Возможности

- Несколько миссий с упражнениями (выбор, заполнение, исправление ошибок)
- Диктант
- Домашнее задание
- Правила грамматики (всегда доступны)
- Отслеживание прогресса и результатов
- Красивый тёмный интерфейс в стиле пещеры / детектива

## Технологии

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- Сборка в **один HTML-файл** (vite-plugin-singlefile)

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

После сборки в папке `dist/` появится один `index.html`, который можно открыть в любом браузере или загрузить на любой хостинг / GitHub Pages.

## Структура проекта

```
src/
├── App.tsx              # Главный компонент и навигация
├── components/          # Упражнения, диктант, результаты и т.д.
├── data/lesson.ts       # Все задания, правила и тексты
├── lib/progress.ts      # Сохранение прогресса (localStorage)
└── assets/caveImage.ts  # Обложка (base64)
```
